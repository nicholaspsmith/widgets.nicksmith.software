# Mascot prompts (manual generation)

Generate each image at https://aistudio.google.com/ (model: an image-capable Gemini
model, e.g. "Nano Banana" / gemini-2.5-flash-image), then save the result as
`art/raw/<id>.png` (a 1:1 PNG, any size). When all are in place run:

```bash
python3 art/gen_icons.py --reprocess
```

This turns the white background transparent, trims, and writes the 256px icons
to `site/img/mascots/`. Prompts below are the exact text the script would send.
